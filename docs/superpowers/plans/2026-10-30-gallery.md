# Gallery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fast, offline Android gallery (photos + videos) that sees every file on the phone. Behaviour exactly as in the spec.

**Architecture:**
- Room is the app's index, filled from MediaStore (incremental, by generation) and a background filesystem walk that catches files MediaStore misses.
- The UI reads only Room: Paging 3 into Compose lazy grids.
- File operations use `java.io.File` under "All files access", then update Room and ask MediaScanner to rescan.
- Everything judgement-heavy lives in `dev.kanorin.gallery.logic` as pure Kotlin with JVM tests: grouping, selection ranges, gestures, zoom maths, validators, policies.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Room + KSP, Paging 3, Coil 3, Media3 ExoPlayer, DataStore Preferences, ExifInterface. Tests: JUnit4, Robolectric, Compose UI test, kotlinx-coroutines-test.

**Spec:** `docs/superpowers/specs/2026-10-30-gallery-design.md` (mockup `gallery-v11.html` beside it). Executors read the spec section each task names.

## Review Focus

1. **Missing or zero `DATE_TAKEN`** (screenshots, downloads, WhatsApp images) must fall back to `dateModified`. They are never grouped under 1970. *Test in Task 3.*
2. **Unicode names** (CJK, emoji, spaces): folder creation, rename, move, search and the duplicate check all work on `"旅行 2026 🌸"`. *Tests in Tasks 9 and 11.*
3. **Files changed by other apps** while the index still holds them. A deleted file leaves the grid on the next sync, and the viewer shows "File no longer exists" instead of crashing. *Tests in Tasks 3 and 13.*
4. **Rotation and recreation mid-action.**
   - Selection survives rotation.
   - Video position and play state survive rotation and the rotate button.
   - *Tests in Tasks 7 and 14.*
5. **Broken or extreme media** (0-byte file, corrupt JPEG, 200 MP image, GIF, HEIC) shows a placeholder tile and never crashes the grid or runs out of memory. *Test in Task 4.*
6. **Move across volumes, or with too little space**, copies first and deletes the source only after the copy is verified (same size). On failure the source is untouched and an error is shown. *Test in Task 9.*
