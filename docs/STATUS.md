- **STATE:** WIRED. Two halves with separate locks, so a new photo never waits for a walk.
  - `syncMediaStore()`:
    1. Delta per volume from the stored generation (0 when none, the version changed or the generation went backwards), in 500-row transactions. Touched folders get their hidden flag.
    2. Delete rows whose id is no longer live (no `File.exists`).
    3. Commit the generations right away, but only for volumes attached with the same version at both the snapshot and the commit. A card pulled mid-sync is read in full when it returns.
  - `fullScan()`:
    1. Walk every mounted root.
    2. New paths become walker rows. A walker row whose size or mtime changed is rebuilt. A walker row the walk didn't see is deleted only if its file is gone too (only the unseen are stat'ed; fix wave M2), so a folder the walk couldn't list keeps its rows.
    3. Every folder's hidden flag is re-checked, with a fresh `.nomedia` lookup (one added mid-walk counts at once).
    4. A MediaStore row written mid-walk is never overwritten.
  - Schedule:
    - Cold start: `syncMediaStore`, then `fullScan`.
    - MediaStore change burst: `syncMediaStore` only, 300 ms debounced; changes during a sync collapse into one follow-up.
    - Resume: `syncMediaStore` every time (round 2 J: Android holds a cached app's observer call ~10 s), `fullScan` at most once per 5 min (never two at once) or after a failed walk.
    - Every 6 h: `fullScan`.
    - Task 10: the Recycle bin's purge, on its own coroutine: every cold start, and on each resume (the bin itself waits 24 h between resume purges).
    - If the observer fails, it resubscribes (1 s doubling to 60 s) and runs one catch-up sync.
  - Hidden root = the mounted root that prefixes the path, so a `.nomedia` at an SD card's top hides nothing.
  - dateTaken: MediaStore value when > 0, else EXIF `DateTimeOriginal` (opened only for those rows and walker rows), else dateModified.
  - MediaStore rows inside `.gallery-bin` are never indexed.
